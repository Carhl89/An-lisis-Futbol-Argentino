⚽ Análisis de Datos del Fútbol Argentino

📌 Descripción del proyecto

Este proyecto consiste en realizar un análisis de datos del fútbol argentino utilizando Python y sus principales librerías para el tratamiento y la visualización de datos.

El objetivo es construir una tabla de posiciones, analizar el rendimiento de los equipos y representar los resultados mediante gráficos.

El proyecto comenzó con un conjunto de datos de práctica de tres equipos: River Plate, Boca Juniors y Racing Club.

🛠️ Herramientas utilizadas

- Python
- Google Colab
- Pandas
- Matplotlib
- GitHub

📊 Análisis realizados

Hasta el momento se desarrollaron las siguientes funcionalidades:

- Creación de un DataFrame con partidos y resultados.
- Cálculo automático de resultados.
- Asignación de puntos por partido.
- Construcción de una tabla de posiciones.
- Cálculo de goles a favor (GF).
- Cálculo de goles en contra (GC).
- Cálculo de diferencia de goles (DG).
- Cálculo de partidos jugados (PJ).
- Cálculo de partidos ganados (PG), empatados (PE) y perdidos (PP).
- Ordenamiento de equipos según puntos y diferencia de goles.
- Visualización de datos mediante gráficos con Matplotlib.

📈 Visualizaciones

Se realizaron gráficos para representar:

1. Puntos obtenidos por equipo.
2. Goles a favor y goles en contra.
3. Diferencia de goles por equipo.
